# 👻 Ghost Mice Go - A Fun Coding App 👻

Welcome to **Ghost Mice Go**! A delightful interactive coding game written in Go where you help a ghost mouse named Boo find all the cheese in a maze!

## 🎮 About the Game

Ghost Mice Go is a fun terminal-based game that combines coding concepts with gameplay. Guide your ghost mouse through a maze by typing commands and collect all the cheese to win!

### Features
- 🧀 Interactive maze navigation
- 👻 Cute ghost mouse character
- 🎨 Colorful emoji-based graphics
- 💡 Learn basic coding commands
- 🎉 Fun animations and feedback

## 🚀 Getting Started

### Prerequisites
- Go 1.16 or higher

### Installation

1. Clone this repository:
```bash
git clone https://github.com/ncdhdhg5253535/ghostmicego.git
cd ghostmicego
```

2. Run the game:
```bash
go run main.go
```

Or build and run:
```bash
go build -o ghostmicego
./ghostmicego
```

## 🎯 How to Play

1. Run the game
2. You'll see a maze with your ghost mouse (👻) and cheese pieces (🧀)
3. Type commands to move the ghost mouse:
   - `up` - Move up
   - `down` - Move down
   - `left` - Move left
   - `right` - Move right
   - `quit` - Exit the game
4. Collect all the cheese to win!
5. Be careful not to hit the walls!
